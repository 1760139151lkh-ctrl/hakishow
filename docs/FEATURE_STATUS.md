# 功能状态

本文区分三种状态：**已实现**（代码已完成）、**已验证**（有实际执行过的检查，见[验证记录](VALIDATION.md)）、**计划中**（尚未实现）。模拟器路径可用与真实服务商路径已完成配置，属于不同的验证条件。

## 延续的开发目标

**用图像模型连续变换每一帧视频仍未实现。** 实时相机的艺术效果由本地着色器、网格形变、分割与贴纸完成；艺术肖像由云端模型在拍照后生成。

| 目标 | 下一项具体步骤 | 负责人 |
|---|---|---|
| 实体设备复核 | 在中端安卓与 iPhone 上测量帧率、发热与跟踪稳定性；按需降低分辨率或关闭分割 | 组员2牵头，组员1协作 |
| 更多三维内容 | 引入轻量三维模型挂件与遮挡（头部遮挡贴纸后半部分） | 组员2 |
| 真实服务商覆盖 | 用真实服务商检查蒙版编辑、变体、角度与失败情况 | 组员2 |
| 实时风格化 | 评估小型风格迁移网络在浏览器中的帧率，作为“实拍”与“AI 艺术”之间的中间层 | 组员2与组员1 |
| 素材扩充 | 为更多特效包补充专属贴纸与音效 | 组员1 |

推进这些目标时，要保持已完成基线可演示。不要用一个标签、不可用的按钮或未来工作说明，替代已经实现的流程。
