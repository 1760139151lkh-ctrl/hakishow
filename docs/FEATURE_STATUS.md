# 功能状态

本文描述交接基线。单独的[验证记录](VALIDATION.md)记载实际执行过的检查。模拟器路径可用与真实服务商路径已完成配置，属于不同的验证条件。

## 当前实现

| 能力 | 现有实现与交接内容 | 验证情况或剩余条件 |
|---|---|---|
| 英语体验 | 界面、帮助、加载／错误消息、生成的指令文字、注释、测试输入和文档 | 对交付项目进行语言与流程审查 |
| 艺术人像创作 | 33 种风格、格式／画质选择、示例素材和工作室任务流程 | 示例和模拟器无需服务商即可使用；真实生成需要配置 |
| 风格与美化控件 | 风格强度、保持相似度、细节丰富度、美化程度、各风格默认值及 264 个细节选项 | 浏览器检查覆盖控件、持久化和版本记录 |
| 照片输入 | 随附人物、文件上传和相机拍摄 | 示例／上传路径无需实体相机；硬件拍摄取决于设备访问条件 |
| 区域编辑 | 12 个区域定义、84 个选项、区域蒙版和绘制工具 | 面部部位和手绘蒙版任务流程可用；模型的确切输出取决于引擎 |
| 本地颜色预览 | 已有面部／头发处理和受支持的着色预览 | 使用随附视觉文件在浏览器中运行；需要检查目标设备性能 |
| 自然语言编辑 | 英语对话、后续建议、多个结果和版本导航 | 模拟器回复与任务流程可用；已配置服务商的回复需要实际检查 |
| 撤销、重做与版本 | 参数撤销／重做、草稿恢复、结果链和源图／结果比较 | 浏览器测试演练修改、重新加载和已存储记录 |
| 作品库与偏好 | 作品、收藏、个人偏好和草稿 | 支持浏览器本地运行；存在工作室服务时支持账户同步 |
| 账户与同步 | 访客状态、注册、登录、归账户所有的素材及记录增量交换 | 服务端测试演练访问边界；浏览器检查覆盖注册和作品恢复 |
| 导出与分享 | 图像保存，以及可用的浏览器分享／下载方式 | 最终系统分享对话框取决于浏览器／设备；保留下载备用方式 |
| 任务恢复 | 进度、取消、已停止／失败状态、重试和重连行为 | 服务端及模拟器浏览器测试覆盖主要路径 |
| 创意风格建议 | 由服务提供的风格定义和英语备用选项 | 真实服务商的创意能力需要另行配置服务并检查 |
| 本地实时预览 | 相机控制器、渲染器、跟踪、风格效果和叠加效果 | 自动化模拟相机检查演练已有实现；实体设备检查另行开展 |
| 响应式应用 | 手机尺寸界面、桌面托管、键盘／安全区域处理、应用清单和服务工作线程 | 浏览器布局检查覆盖指定视口；不表示对所有实体设备作出保证 |

## 延续的开发目标

**完整的实时艺术变换尚未完成。** 现有相机效果、跟踪和叠加效果都是有用的实现，但不能证明已具备连续全画幅图像模型变换能力。研究更高水平的效果质量时，应保留当前处理路径。

| 目标 | 下一项具体步骤 | 负责人 |
|---|---|---|
| 更丰富的实时变换 | 建立相机性能基准，选择渲染／推理方案，并交付一种稳定的艺术效果 | 杰克牵头，艾米协作 |
| 真实服务商验证 | 配置预定账户和模型，然后测试人像生成、蒙版编辑、变化版本、进度和失败情况 | 杰克 |
| 实体手机与虚拟机审查 | 在预定设备上测试相机权限、设备直通、方向、内存、触控编辑和导出 | 艾米与杰克 |
| 最终挑战材料 | 根据已展示的成果，制作最终报告、演示文稿、带解说录像和贡献评审 | 迈克协调全体成员 |
| 额外外部原图 | 审查以后提供的原始素材或可编辑文件，保留独特且有用的内容，并更新素材目录 | 艾米 |

推进这些目标时，要保持已完成基线可演示。不要用一个标签、不可用的按钮或未来工作说明，替代已经实现的流程。
