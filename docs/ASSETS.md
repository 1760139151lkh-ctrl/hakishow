# 美术素材与本地模型

交接包在 `web/img/` 下包含 **393 个图像文件**，覆盖 **183 组主要美术素材**及其有用的尺寸变体。在英语改编过程中，所有随附图像的字节内容均予以保留。文件命名、创作描述和引用关系一并进行了规范化。

## 随附美术素材

| 分组 | 主要素材数量 | 随包图像文件数量 | 用途 |
|---|---:|---:|---|
| 人物 | 6 | 18 | 源人像及其卡片／缩略图版本 |
| 风格人像 | 99 | 297 | 每种风格提供三位示例人物，均有完整、中等和缩略图尺寸 |
| 背景 | 34 | 34 | 各风格专属的视觉环境 |
| 透明贴纸 | 31 | 31 | 实时叠加效果和界面装饰 |
| 场景选项 | 12 | 12 | 背景编辑选项 |
| 品牌素材 | 1 | 1 | 应用品牌图像 |
| 合计 | 183 | 393 | |

这些图像文件总计 **35,550,116 字节**。应用还包含 PNG 安装图标、六个随附字体文件、相机测试样本和本地视觉模型，它们不计入此图像目录。

此目录中没有字节内容完全相同的重复图像。完整人像、中等尺寸卡片和方形缩略图是各自有用的不同输出，因此全部保留。同样，透明贴纸与背景即使主题相同，也不能互相替代。

保留了原有的尺寸组：37 组人像使用 1024 × 1536、540 × 810 和 240 × 240；68 组使用 720 × 1080、360 × 540 和 192 × 192。背景为 540 × 810，场景选项为 256 × 256，品牌图像为 128 × 128。透明贴纸的最长边为 512 像素。本次交接没有放大或重新压缩任何图像。

## 名称与引用

- `web/img/manifest.json` 是可由程序读取的人物、风格示例、背景、贴纸和场景清单。
- `web/img/provenance.json` 保留 281 条模型／日期及来源记录，包括有用的历史变体，并带有英语创作描述。改编后的描述使用 `creative_reference` 字段。
- `web/js/presets.js` 将全部 33 个风格预设与其素材、主题、默认值和提示词关联起来。
- `web/js/parts.js` 定义 12 个区域和 84 个区域选项。
- 每种风格提供八个细节选项：33 种风格共 264 个选项。

七个分类分别是**精选、趣味、角色、幻想、动漫、氛围和艺术**。品牌和控件使用英语；受日本风格启发的视觉创意可以使用易读的拉丁字母名称。

## 保留检查

审查将每张图像与改编前的 SHA-256 指纹逐一匹配。检查内容包括重命名后的引用、目录条目、图像数量和配置结构。还查看了覆盖全部主要素材组的缩略图总览，并对小型装饰标牌进行了更细致的检查。没有发现需要替换位图才能处理的可读嵌入文字。现有的日期装饰和罗马数字仍作为图像的一部分保留。

这些文件是所提供项目中的全部美术素材。原项目中没有提供的更大尺寸生成原图、可编辑设计文件或额外个人桌面材料，不包含在内。即使没有这些外部文件，随附的完整分辨率网页素材仍然可用。

## 使用素材

直接使用当前素材目录运行或开发应用。不要把重新生成整套图像作为安装步骤。

如果未来明确需要生成新素材：

```sh
uv run python tools/make_assets.py --help
uv run python tools/process_assets.py
```

`make_assets.py` 使用已配置的图像接口，并将生成原图写入 `private/assets-raw/`。处理命令要求完整的原始素材文件夹，生成网页所需的各种尺寸，并更新清单。在修改已有派生文件之前，它会先检查是否缺少源文件。新增素材时应保留原始文件和可编辑版本，并在替换随包素材之前审查生成内容。

应用运行不需要本地生成工作区；该工作区和个人运行数据均不随包提供。共享新生成的原图时，应挑选经过审查、使用英语名称的文件，放入明确的源素材文件夹，并记录它们与运行时文件的对应关系。

## 字体与视觉模型

`web/fonts/` 包含 Fraunces、Courier Prime、VT323、Instrument Serif、Space Grotesk 和 Cinzel。`web/vendor/mediapipe/` 包含浏览器视觉模块、WebAssembly 运行时、面部关键点模型和头发分割模型。它们支持本地处理，使演示过程中无需从其他网站获取模型文件。

依赖清单见 `web/vendor/README.md`。面部和头发模块处理本地相机或图像流程；服务端生成是使用所选工作室引擎执行的另一项独立操作。
