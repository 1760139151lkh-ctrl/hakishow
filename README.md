# HakiShow

**让一张自拍，成为值得创作的人像。** HakiShow 是一个以新加坡为重点、具有亚太视觉视野的英语创意人像工作室。你可以探索 33 种风格、调整外观、编辑选定区域，并通过对话描述想要的变化。

迈克（Mike）、艾米（Amy）和杰克（Jack）是在西班牙就读的大学生，他们共同参与这项创意计算挑战。项目从一个可运行的人像工作室演示程序起步，为团队探索设计、成像和软件工程提供空间。这是一个具备真实操作流程和明确后续开发计划的学习型原型。

## 从这里开始

使用 Node.js 22 或更新版本、Python 3.12 或更新版本，以及 uv。在项目目录中运行以下命令：

```sh
npm ci
uv sync --locked
npm run build
uv run likeness serve --engine simulator
```

打开 `http://127.0.0.1:8787/`。模拟器无需托管图像服务即可演练完整的服务端工作流程。其输出会标注为**模拟结果**。可以用它体验账户、上传、局部编辑、对话、版本以及作品库同步。

如需仅在浏览器中运行的静态演示：

```sh
npm run serve
```

打开 `http://127.0.0.1:4173/`。示例人像使用随附的美术素材；上传的图像使用本地预览。静态演示不提供服务端账户或托管图像生成。

## 创作一张人像

1. 打开**实时相机**或**照片工作室**。也可以选择随附的示例人像。
2. 选择一种风格。每种风格都有自己的配色、边框、细节和实时效果。
3. 调整风格强度、相似度、细节丰富度和美化程度；选择输出格式和画质。
4. 使用**区域**选择面部区域，或自行绘制蒙版。在本地预览受支持的颜色变化。
5. 使用**对话**描述另一项修改、创建变化版本，或探索不同角度。
6. 比较版本、撤销或重做、保存图像，并在**作品库**中再次查看。

全部 33 个风格预设和七个分类均予以保留。原始人像素材、场景背景和透明贴纸均已包含在内。参见[素材目录](docs/ASSETS.md)。

## 各种模式分别提供什么

| 模式 | 提供的能力 | 所需条件 |
|---|---|---|
| 静态展示 | 随附示例、本地效果、编辑控件和浏览器存储 | Node.js 静态服务器和浏览器 |
| 模拟器工作室 | 完整的请求、任务、账户、同步和编辑流程，渲染结果由模拟器提供 | Python 工作室服务器 |
| 托管图像工作室 | 使用已配置的服务提供商生成和编辑图像 | 自行提供可用的服务商配置和凭据 |
| 浏览器实时预览 | 相机输入、本地渲染、跟踪和受支持的叠加效果 | 支持相机的浏览器和合适的设备 |

浏览器实时渲染是已有的实现，同时也是持续开发的方向。它与使用托管图像模型连续生成每一帧视频不同。完整的实时艺术变换仍是产品目标；参见[功能状态](docs/FEATURE_STATUS.md)和[后续步骤](docs/NEXT_STEPS.md)。

## 连接托管图像服务

将 `.env.example` 复制为 `.env.local`，在本地填入自己的服务商凭据，并检查 `studio.toml` 中的模型和画质设置。然后运行：

```sh
uv run likeness serve --engine openai
```

项目不包含任何服务商凭据。真实服务的输出和响应时间取决于配置的账户和模型。自动化测试使用本地测试替身或模拟器；它们不能证明真实服务商当前可用。

## 手机和虚拟机使用

应用采用响应式布局，可以在手机上打开。相机访问需要允许摄像头采集的浏览器环境：在同一台电脑上进行本地开发，或者为其他设备配置合适的 HTTPS 地址。虚拟机必须向其中的浏览器提供可用相机。如果无法使用相机，可以继续使用示例和上传流程。

局域网使用方式见[安装与运行](docs/SETUP.md)。需要从本机以外访问时，请使用工作室的所有者私有链接配置，并将服务商凭据保留在工作室服务器上。

## 项目目录说明

| 路径 | 用途 |
|---|---|
| `web/` | 响应式浏览器应用、本地渲染和随附美术素材 |
| `web/js/presets.js` | 风格数据、主题、参数和图像提示词 |
| `web/js/parts.js` | 区域定义和编辑选项 |
| `web/js/core/` | 导航、数据、账户、请求、生成和版本状态 |
| `web/js/live/` | 相机、渲染、跟踪和叠加效果 |
| `web/js/studio/` | 风格面板、本地区域、绘制和对话 |
| `likeness/` | FastAPI 工作室、账户、图像任务、存储和引擎 |
| `tools/` | 浏览器构建、本地展示服务器和美术素材工具 |
| `tests/` | 服务端和浏览器回归测试 |
| `docs/` | 项目计划、挑战要求、团队职责和交接说明 |

`likeness` 是内部 Python 模块名和命令名。面向用户的体验统一使用产品名称 HakiShow。

## 开发与检查

```sh
npm run check
npm run build
uv run pytest
npm test
```

首次使用时，通过 `npx playwright install chromium` 安装浏览器运行环境。扩展的手机布局和交互测试套件使用 `npm run accept`；安装 WebKit 后，还可以启用受支持的 WebKit 检查。

开展自动化开发前，请先阅读 [AGENTS.md](AGENTS.md)。本次交接实际执行了哪些检查，请以[验证记录](docs/VALIDATION.md)为准，不要假定所有设备或托管服务都已经测试过。
